# fkmanager-360-poc

## Agent skills

### Issue tracker

Issues live as GitHub issues in `fkazeredo/fkmanager-360-poc`, managed with the `gh` CLI. Specs and implementation work are both tracked there. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context, documentation lives in this repository: the domain glossary is `CONTEXT.md` at the root and ADRs live in `docs/adr/`. See `docs/agents/domain.md`.
